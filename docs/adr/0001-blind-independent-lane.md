# 独立通道对主脑结论保持盲性

独立通道被刻意做成**看不到主脑动作、理由、置信度、入场、止损、止盈**。这是为了
让"模型是否独立认同这笔交易"成为可测量的量：一旦它看到主脑的结论，问题就退化成
条件确认，而条件确认**不可能证伪主脑**——它只能复述。这条通道的全部价值在于它能
给出主脑没想到的答案。

Status: accepted

## Considered Options

- **A. 把两条通道合并成一个请求**（省一次 HTTP、省 token）。方案 §3 明确否决：
  独立通道的所有问题会看到同一个 state，因此无法再靠问题名称区分"独立判断"与
  "提案审计"。两条通道必须用两个 state。
- **B. 给独立通道一个"中性锚"**，例如注入一份虚构的 `WAIT` 提案，让它有参照物而
  不泄漏真实结论。讨论中提出过，**未采纳**：虚构一份提案等于注入一个会扭曲独立性
  的先验，而被注入的先验无法事后从台账里剥离——代价是永久性的，收益是临时的。
- **C. 让独立通道看到真实提案，只在提示词里要求"请独立判断"**。这是最容易想到的
  做法，也是**最危险**的：无法验证模型是否真的忽略了这个锚，账台上看起来是独立
  判断、实际上可能是条件确认，而**假分歧比没有分歧更糟**，因为它会被当成证据。

## Consequences

盲性是**有代价的，而且代价可以被测量**。同一批周期、**市场事实逐字节相同**
（`audit_state.neutral_market_state` 与 `independent_state.market` 相等，两个
state hash 不同），只有"有无主脑提案作参照"这一个变量不同：

| 口径 | 有锚 | 中位 |
|---|---|---|
| `audit_data_valid`（有锚） | 是 | **0.62** |
| `cycle_data_valid`（无锚，整轮） | 否 | **0.45** |
| 逐候选 `data_valid`（无锚，最细） | 否 | **0.36** |

（校准上线前，n=9 轮。旧单通道时代中位 0.58~0.65，但旧记录**不存 state**，
其"有锚"属**推断**而非验证，故不作为主要依据。）

由此产生两个非显然的连带后果：

1. **门槛会结构性不可达。** 去掉锚之后整条答案分布下移，而门槛是按有锚分布标定
   的（旧 `would_wait` 中位 0.79）。实测：90 个候选里 **0 个**达到 0.70 的
   confidence 门槛，**0 个**方向性输出。这是盲性的直接代价，不是模型故障。
2. **盲性比最初估计的更可负担。** 上述压缩有相当一部分**不是结构性的，而是测量
   缺陷**：题面从未写明量表语义。补上校准说明后，无锚逐候选中位 **0.36 → 0.66**、
   标准差 0.098 → 0.161、上限 0.64 → 0.84，方向信号随即产出。
   **所以遇到"这个通道答得太保守"时，先改测量，不要先取消盲性。**
   取消盲性是不可逆的（作废全部已积累证据），改测量是可回滚的。

因此：任何为了"让它别那么保守"而给独立通道加锚的提议，都应先证明已穷尽测量侧的
改进。改变盲性会作废此前全部影子样本，并需要重新标定所有门槛。
